# Support

Need help with a project? Please use the appropriate support channel provided by the repository.

## Before Asking for Help

* Check the project's README and documentation.
* Search existing issues and discussions.
* Make sure you are using a supported version.
* Provide relevant details when asking for help.

## Getting Help

Depending on the project, support may be available through:

* GitHub Issues for bugs and actionable problems.
* GitHub Discussions for questions and general discussion.
* Project documentation for usage and configuration questions.

When requesting support, include enough information to understand the problem, such as relevant error messages, steps to reproduce, and your environment where applicable.
