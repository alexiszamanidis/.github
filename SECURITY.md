# Security Policy

## Supported Versions

Security updates are provided for actively maintained and supported versions of the project.

## Reporting a Vulnerability

Please **do not report security vulnerabilities through public issues**.

If the repository has GitHub's private vulnerability reporting enabled, please use it to report the vulnerability privately.

Otherwise, contact the repository maintainer privately with:

- A description of the vulnerability
- Affected version(s)
- Steps to reproduce
- Any relevant logs or evidence

Please avoid including secrets, credentials, or personal data in your report.
